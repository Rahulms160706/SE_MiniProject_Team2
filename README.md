# Online Bookstore

## 1. Project Overview

The Online Bookstore is a web-based application designed to allow customers to browse and search for books, manage their shopping carts, place orders, and view their order history. Sellers can add book listings to the platform.

## 2. Objectives

- Provide a platform for browsing and searching books.
- Allow customers to manage their shopping carts and place orders.
- Allow sellers to create book listings.
- Implement user authentication and role-based access control.
- Protect user data and maintain consistent order records.

## 3. Technology Stack

- **Programming Language:** Python
- **Web Framework:** Django
- **Database:** To be finalized by the project team
- **Frontend:** HTML, CSS, and JavaScript as required
- **Version Control:** Git and GitHub
